# WithGod

AI-powered React & React Native app using RAG and LLM to deliver personalized Bible verses and comfort.

## Monorepo

- `WithGod/`: Expo React Native app
- `withgod-web/`: Next.js web app
- `backend/`: FastAPI RAG API and push notification backend

Backend environment files such as `backend/.env` are ignored by Git and should be shared only through a private channel.
