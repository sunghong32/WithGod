# 스토어 개인정보 신고 (분석 수집 반영)

앱이 분석 데이터를 수집하므로 Play Console "데이터 보안"과 App Store "앱 개인정보
보호"에 신고가 필요하다. 이 문서는 **실제 코드가 보내는 것**을 근거로 정리한
것이다 — 추정이 아니라 아래 파일에서 확인한 내용이다.

- 앱이 보내는 값: `WithGod/src/shared/lib/telemetry/index.ts`
- 서버가 받아주는 파라미터 키: `backend/analytics/schema.py`

> 2026-07 기준. 수집 항목을 늘릴 때 이 문서와 스토어 신고를 함께 갱신할 것.

## 실제로 나가는 데이터

**자체 수집(mincha.co.kr)** — 배치마다:

| 필드 | 값 | 개인 식별성 |
|---|---|---|
| `anon_id` | 앱이 만든 임의 문자열(`withgod.deviceId`) | 익명. 계정 없음, 재설치하면 새 값 |
| `platform` / `os_version` | `ios` / `18.2` | 기기 정보 |
| `app_version` | `1.2.0` | 앱 정보 |
| `tz` | `Asia/Seoul` | 대략적 지역(도시 수준 아님) |
| `session_id`, `event_id`, `ts` | 임의 문자열, 시각 | — |
| `params` | 화이트리스트 키만 | 아래 참고 |

허용 파라미터는 `screen_name` `source` `reference` `from` `length` `index`
`count` `duration_ms` `style` `result` `enabled` `reason` 뿐이다.
**사용자가 입력한 마음 텍스트는 앱에서 보내지 않고, 서버도 그 키를 받지 않는다**
(`mood_submit` 은 글자 수 `length` 만 남긴다).

**Firebase Analytics** — 같은 이벤트를 함께 보낸다. Firebase 는 위 항목 외에
앱 인스턴스 ID와 **IP 기반 대략적 위치**, 기기 모델 등을 자동 수집한다. 신고는
자체 수집이 아니라 **Firebase 기준으로 하는 쪽이 안전**하다(더 넓다).

## Play Console — 데이터 보안

**데이터 수집: 예 / 데이터 공유: 예**(Firebase = Google, 제3자 처리자)

| 데이터 유형 | 수집 | 공유 | 목적 | 필수 여부 |
|---|---|---|---|---|
| 앱 활동 › **앱 상호작용** | 예 | 예 | 분석 | 선택(앱 내 끄기 가능) |
| 기기 또는 기타 ID › **기기 또는 기타 ID** | 예 | 예 | 분석 | 선택 |
| 위치 › **대략적인 위치** | 예 | 예 | 분석 | 선택 |

- 위치는 **Firebase 가 IP로 추정하는 것** 때문에 신고한다. 자체 수집은 위치를
  보내지 않는다. Firebase 를 떼면 이 줄은 빼도 된다.
- 전송 중 암호화: **예** (HTTPS)
- 데이터 삭제 요청 가능: **예** — 계정이 없으므로 "앱 삭제 시 기기 ID가 폐기되고
  이후 수집이 중단됨"으로 안내한다.
- "사용자가 데이터 수집을 선택 해제할 수 있음": **예** (설정 › 사용 통계 보내기)

## App Store — 앱 개인정보 보호

**사용자 신원에 연결되지 않은 데이터(Data Not Linked to You)** 로 신고한다.
계정 체계가 없어 신원과 연결할 방법이 없다.

| 데이터 유형 | 용도 |
|---|---|
| 식별자 › **기기 ID** | 분석(Analytics) |
| 사용 데이터 › **제품 상호작용** | 분석 |
| 진단 › (해당 없음) | — |

- **추적(Tracking): 아니요.** 광고 SDK가 없고, 데이터를 제3자 광고/데이터 브로커에
  넘기지 않는다. 따라서 ATT 팝업(AppTrackingTransparency)도 필요 없다.
- Firebase 를 광고 목적으로 쓰기 시작하면 이 답이 뒤집힌다.

## 개인정보처리방침에 추가할 문구

방침 문서는 이 저장소에 없다(스토어에 URL 로 등록돼 있음). 아래 취지의 문단을
추가해야 한다.

> **수집 항목** 앱 이용 통계(화면 이동, 기능 사용 여부), 임의로 생성된 기기 식별자,
> 앱·OS 버전, 시간대.
> **수집 목적** 서비스 개선을 위한 이용 현황 분석.
> **보관 기간** 개별 이용 기록은 90일간 보관 후 삭제하며, 식별자가 제거된 통계
> 수치만 보관합니다.
> **제3자 제공** Google Firebase(분석). 그 외 제3자에게 제공하지 않으며 광고
> 목적으로 이용하지 않습니다.
> **거부 방법** 앱 설정 › 사용 통계 보내기 를 끄면 수집이 중단됩니다.
> **수집하지 않는 것** 이용자가 입력한 마음/기도 내용은 서버로 전송되지 않습니다.

남아 있다. 어차피 데이터 보안을 손봐야 하니 한 번에 정리하는 게 낫다.
