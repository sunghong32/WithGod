## 지금 상태

**오늘의 말씀 기준을 「비신자에게도 와닿는가」로 넓혀 81개를 뺐다(11/2, 운영 배포).** 이사야 25:8 이
어떤 위로인지 모르겠다는 사용자 지적이 계기. 457 → 376개(신자·특정인 대상 18 · 교리 용어 17 · 문맥 의존 16 ·
신앙 실천 14 · 고백·계명 8 · 종말 3 · 기타 5). 부활절 말씀은 요한복음 16:22 로 바꾸고, 성탄 말씀(눅 2:14)은
성탄 전용으로 돌렸다(`_HOLIDAY_ONLY`). **풀이도 같은 기준으로 다시 봐 224개를 고쳤다(11/3, 운영 배포)** —
기도로 맺는 끝 62개 → 0, 신앙 실천 권유·신자 전제·풀지 않은 교회 말을 걷어 냄. **외국어 7개 언어도 즉석 생성을
그만두고 검토본(376 × 7 = 2,632개, 한국어 검토본 바탕 + 자동 검사)을 낸다(11/3, 운영 배포).** 한국어 풀이를 고치면
`scripts/generate_intl_interpretations.py --fix` 로 외국어도 다시 만든다. 작업 문서 6·7·8번.

**생성 AI 를 OpenAI → Claude Haiku 5.5 로 옮겼다(11/2).** OpenAI 는 9/18부터 결제가 막혀(`billing_not_active`)
위로의 말씀이 첫 카드에서 끊기고 오늘의 말씀 풀이가 한 줄 폴백으로 나갔다. 호출은 `backend/llm.py` 한 곳에 모았다
(키 `ANTHROPIC_API_KEY`, 모델 `LLM_MODEL`, 기본 `claude-haiku-5-5`). Haiku 5.5 는 temperature 를 받지 않고(400),
JSON 은 스키마(`output_config.format`)로 강제한다. 짧은 호출은 생각(thinking)을 끄고, 외국어 풀이만 켠다.
Claude 토크나이저가 한국어를 더 많이 세서 코멘트 상한을 두 배(카드당 500 → 1000)로 올렸다 — 그대로 두면 JSON 이 잘린다.
OpenAI 시절 이탈리아어만 gpt-4o 로 올리던 장치는 `LLM_MODEL_IT`(비우면 기본 모델)로 남겼다.

**오늘의 말씀 풀이를 새로 썼다(9/18, 운영 미배포).** 풀이가 대충이고 사용자에게 반말을 한다는 지적
(「**너의** 잘못을 용서받았다는 말씀이에요」). 한국어 457개를 gpt-5.5 로 초안을 만든 뒤 전부 검토해
262개를 고쳤고(사실 5·오독 24 포함), 저장소에 검토본으로 넣었다(`docs/verse_picks/interpretations.tsv`
→ `notifications/daily_interpretations.json`). 운영은 한국어는 검토본을 내고 외국어만 즉석 생성(Claude Haiku 5.5, 11/2부터)한다.
반말·반말 어미·본문 되옮기기 검사가 생성·빌드·테스트에 걸려 있다. 추천 코멘트에도 호칭 규칙을 넣었다.
자세한 건 작업 문서 5번.

**오늘의 말씀 목록을 처음부터 다시 만들고 있다.** 385개를 전수 감사했더니 163개(42%)가
부적합이었다 — 61권 균등 배분 때문에 룻기·에스라에서 바닥을 긁었고, 시편은 26개뿐이었다.
성경 전체를 다시 읽어 793개까지 모은 뒤 **전수 재검토를 끝냈다(탈락 364개, 46%).**
남은 것이 **429개**(위안 167 · 교훈 262). **표본 검증도 통과했다(3/40 = 7.5%, 기준 3개 이하).**
**남은 구약 23권(5,190절)도 다 읽었다** — 28개 채택(0.54%). 역사서는 이야기이고
나머지는 율법과 심판 선언이라 카드로 뗄 절이 거의 없다(레위기·아가·룻기 등 12권은 0개).
**목록 457개(11/2 이후 376개)를 `daily_verses.json` 에 반영했고 부수 작업도 끝냈다** — 날짜 편중 해소,
절기 고정 배치(새해·부활절·성탄·**설날·추석**), 풀이 프롬프트 개선.
설날·추석은 **한국 음력** 날짜표를 쓴다 — 중국 음력으로 계산하면 2027·2028 설날이 하루씩 틀린다.

배포 직전에 **#31 복구가 사용자에게 안 닿고 있던 것**을 찾아 고쳤다. 앱은 `verses.csv` 가 아니라
`verses_meta.parquet`·`verses.faiss` 를 읽는데 CSV 만 고쳐 두었었다. 바뀐 161행만 같은 모델로
다시 임베딩해 반영했다(`scripts/sync_index_with_csv.py`). 반영 전에는 신명기 4:31 을 찾으면 4:32 가,
시편 3:8 을 찾으면 3:7 의 본문이 나왔다.

**외국어 변환이 합본·하반절 참조를 못 읽던 결함을 고쳤다(#32, 9/19 운영 배포).** 재선정으로 들어온
`시편 40:1-2`·`요한복음 8:11b` 꼴 36개(8%)를 `languages.localize_ko_ref` 가 해석하지 못해, 그날은
외국어 7개 언어 사용자에게 **한국어 카드·푸시가 나갔다**(9/17 요한 8:11b, 9/18 하박국 3:17-18).
합본은 범위를 한 창으로 정렬해 이어 붙이고(절마다 따로 맞추면 fr 시편 40:1-2 가 40:2 를 두 번 고른다),
하반절은 외국어에서 절 전체를 싣고 `b` 를 뗀다. 목록 전부 × 7개 언어로 변환되는지 데이터 테스트로 지킨다.
