# @withgod.app 런칭 게시물 9개 — 캡션

올리는 순서는 아래 번호 순서(오래된 것부터). 그리드는 최신이 왼쪽 위라서 거꾸로 올린다.
하루 3개씩 사흘에 나눠 올린다(1~3 → 4~6 → 7~9). 마지막 날 고정용 3개를 올린 뒤 **03 → 02 → 01 순서로 고정**하면 01 이 맨 왼쪽에 온다. 순서가 다르게 보이면 고정을 풀고 다시 고정한다.
캡션은 코드 블록을 그대로 복사해 붙인다. 대체 텍스트는 각 게시물의 고급 설정 → 대체 텍스트에 넣는다.
