# AI 코딩 컨텍스트 관리 가이드 (팀 공유용)

> Claude Code(및 유사 AI 코딩 에이전트)로 이 저장소를 작업할 때, **세션이 바뀌어도 맥락이 이어지도록** 하는 방법입니다.
> 이미 이 저장소에 세팅돼 있으니 **새로 하실 건 없고** — 원리와 운영 방식만 이해하시면 됩니다.

---

## 1. 왜 하는가

AI 코딩 에이전트는 **대화(세션)가 끝나면 맥락을 잊습니다.** 컨텍스트 창이 꽉 차거나, 다음 날 새로 열거나, 팀원이 이어받으면 지금까지 뭘 왜 했는지 다시 설명해야 합니다.

그래서 겪는 문제:

- **매번 다시 설명** — "이 프로젝트는 이런 거고, 지난번에 여기까지 했고…" 반복.
- **오락가락** — 에이전트가 이미 내린 결정·이미 고친 걸 다시 건드림.
- **팀원 간 단절** — A가 시킨 작업 맥락을 B가 모름.

**해결책**: 프로젝트의 "지금 상태"와 "앞으로 할 일"을 **파일 하나**에 적어두고, **세션이 시작될 때 자동으로 에이전트에게 읽힙니다.** 사람이 매번 설명할 필요가 없어집니다.

핵심 원칙 하나: **작업이 끝나면 그 파일을 갱신한다.** 안 하면 금방 낡아서 무용지물이 됩니다.

---

## 2. 무엇으로 구성되나

| 파일 | 역할 | 갱신 시점 |
|------|------|-----------|
| **`docs/STATUS.md`** | **지금 상태 + 앞으로 할 일** — 완료/진행/예정, 우선순위(P1/P2/P3), 알려진 한계, 최근 변경 이력 | 작업 **완료할 때마다** |
| **`CLAUDE.md`** (루트) | 온보딩 문서 + 변하지 않는 규칙. 맨 위에 "작업 전 STATUS.md 먼저 읽어라" | 프로젝트 구조·규칙이 바뀔 때 |
| **`.claude/settings.local.json`** | **SessionStart 훅** — 세션 시작 시 STATUS.md를 자동 주입 | 거의 안 건드림(개인 설정) |
| **`~/.claude/scripts/inject-status.sh`** | 훅이 실행하는 공용 스크립트. 크기 감시 포함 | 거의 안 건드림 |

```
저장소/
├─ CLAUDE.md                      ← "시작 전 docs/STATUS.md 읽어라" + 규칙
├─ docs/
│   ├─ STATUS.md                  ← 지금 상태 + 로드맵 (팀 공유·커밋)
│   └─ 컨텍스트관리_가이드.md       ← 이 문서
└─ .claude/
    └─ settings.local.json        ← SessionStart 훅 (개인, .gitignore)
```

> **왜 파일 하나인가**: STATUS와 PLAN을 나누면 둘 다 낡고 서로 어긋납니다. 한 파일 안에 「지금 상태」와 「앞으로 할 일(P1/P2/P3)」 섹션을 두는 편이 관리가 쉽습니다.

> **커밋 여부**: `docs/STATUS.md`는 팀 공유용이라 **커밋**합니다. `.claude/settings.local.json`은 개인 로컬 설정이라 **`.gitignore`** 처리합니다.

---

## 3. 어떻게 동작하나

```
새 세션 시작
   │
   ├─ [SessionStart 훅] docs/STATUS.md 를 자동으로 읽어 에이전트에 주입
   │      → 에이전트가 "지금 상태·앞으로 할 일"을 이미 알고 시작
   │
   ├─ 작업 수행
   │
   └─ 작업 완료 → docs/STATUS.md 갱신 (지금 상태 + 최근 변경 이력)
```

핵심은 **자동 주입**(훅)과 **작업 후 갱신**(규칙)의 조합입니다. 둘 중 하나만 있으면 안 됩니다.

---

## 4. ⚠️ STATUS.md 는 20KB 아래로 유지할 것

이 파일은 **세션이 시작될 때마다 통째로 주입**됩니다. 즉 파일이 커지면 **그 세션의 모든 요청이 비싸집니다.** 컨텍스트는 매 요청마다 다시 읽히기 때문입니다.

실제로 겪은 사례: 한 저장소의 `CLAUDE.md`에 운영 사고 이력을 계속 쌓았더니 270KB(약 42k 토큰)가 되었고, 그 프로젝트는 **아무것도 하지 않아도 42k 토큰에서 세션이 시작**됐습니다.

그래서 훅 스크립트가 크기를 감시합니다:

| 크기 | 동작 |
|---|---|
| ~20KB | 정상 주입 |
| 20KB 초과 | 전체 주입 + "줄이세요" 경고 |
| 40KB 초과 | **앞부분만 주입** + 잘렸다고 알림 |

**지켜야 할 것**: 완료된 작업 이력은 `CHANGELOG.md`나 git history로 넘기고, `docs/STATUS.md`에는 **지금 상태와 앞으로 할 일만** 남깁니다. 「최근 변경 이력」도 최근 5~10줄만 유지합니다.

## 5. 다른 저장소에 적용할 때

### ① `docs/STATUS.md` 만들기

```markdown
# STATUS — 프로젝트명

> 이 저장소의 **지금 상태 + 앞으로 할 일**. 세션이 바뀌어도 여기만 읽으면 이어서 작업할 수 있다.
> **작업을 완료하면 「지금 상태」와 「최근 변경 이력」을 갱신할 것.**
> ⚠️ 이 파일은 세션 시작 시 통째로 주입된다. **20KB 아래로 유지할 것.**
> 최종 갱신: YYYY-MM-DD · 브랜치: `main`

## 한 줄
## 지금 상태
## 진행/예정
## 앞으로 할 일 (우선순위)
### P1 — 지금 바로
### P2 — 다음
### P3 — 이후
## 알려진 한계
## 최근 변경 이력
```

### ② `CLAUDE.md` 맨 위에 필독 규칙

```markdown
## ⚠️ 작업 시작 전 필독 (반드시)

작업을 시작하기 전에 **[docs/STATUS.md](docs/STATUS.md) 를 반드시 먼저 읽을 것.**

**작업을 완료하면 `docs/STATUS.md` 를 갱신할 것** — 「지금 상태」와 「최근 변경 이력」에
무엇을·왜 했는지 한 줄. 새 개선 항목은 「앞으로 할 일」에 넣는다.
```

### ③ SessionStart 훅 등록 (각자 자기 PC에서 1회)

`.claude/settings.local.json` (없으면 새로 만들기):

```json
{
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "/Users/<사용자명>/.claude/scripts/inject-status.sh",
            "statusMessage": "컨텍스트 복원(docs/STATUS.md)"
          }
        ]
      }
    ]
  }
}
```

- 이 파일은 개인 설정이므로 `.gitignore`에 `/.claude/settings.local.json`을 추가합니다.
- 등록 후 **Claude Code를 새로 시작**해야 훅이 로드됩니다.
- 확인: 새 세션 상단에 "컨텍스트 복원(docs/STATUS.md)" 이 뜨고, 에이전트가 프로젝트 상태를 이미 알고 있으면 성공.

## 6. 일상 운영

1. **작업 시작**: 그냥 세션을 열면 훅이 STATUS.md를 읽어줍니다. 수동으로 설명할 필요 없습니다.
2. **작업 완료**: CLAUDE.md 규칙 덕에 에이전트가 알아서 갱신합니다. 안 하면 "STATUS.md 갱신해줘"라고 하세요.
   - 최근 변경 이력에 **무엇을·왜** 한 줄 (날짜 포함).
   - 새 개선 아이디어는 「앞으로 할 일」에.
3. **커밋**: `docs/STATUS.md`도 코드와 함께 커밋 → 팀 전체가 같은 맥락 공유.

### 이것만 지키면 됩니다

- ✅ STATUS.md는 **항상 지금 상태**를 반영 (낡으면 신뢰가 무너짐)
- ✅ 커밋할 때 STATUS.md도 같이
- ✅ **20KB 아래로 유지** — 완료 이력은 CHANGELOG.md나 git history로
- ❌ 코드에서 이미 알 수 있는 것(파일 구조·git 히스토리)은 중복 기재하지 말 것 — **"왜/맥락"** 위주로

---

## 7. 세션을 새로 여는 것도 중요합니다

이 구조의 전제는 **작업 단위마다 새 세션을 여는 것**입니다. 한 세션을 며칠씩 끌면 대화가 계속 쌓여 컨텍스트가 수십만 토큰이 되고, 매 요청이 그만큼 비싸집니다.

- 터미널에서 `claude`를 새로 실행 → 이전 컨텍스트 없음 (권장)
- 같은 창에서 주제만 바뀜 → `/clear`
- **텔레그램 브릿지 경유 → 자동으로 이전 세션을 이어받으므로 `/new`** 로 끊어야 함

---

## 8. 한 줄 요약

> **"지금 상태 + 할 일"을 `docs/STATUS.md` 하나에 두고, 세션 시작 시 자동으로 읽히게(훅) 하고, 작업 끝나면 갱신한다. 단 20KB를 넘기지 않는다.**
