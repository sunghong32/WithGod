# 오늘의 말씀 재선정 — 작업 문서

> 진행 중인 대형 작업. 새 세션은 **이 문서를 먼저 읽고** 「다음 할 일」부터 이어간다.
> 최종 갱신: 2026-09-02

## 왜 하는가

`notifications/daily_verses.json` 의 385개 목록을 전수 감사한 결과 **163개(42%)가 오늘의
말씀으로 부적합**했다(감사표: `docs/daily_verses_audit.csv`).

근본 원인은 **61권 균등 배분(라운드로빈)**이다. 명작 밀도는 책마다 다른데 균등하게
뽑으라고 하니 룻기·에스라·역대하에서 바닥을 긁었다 — 보아스가 추수꾼에게 건넨 인사
(룻 2:4), 아사 왕의 축성 기록(대하 14:6), 고레스 칙령(스 1:3). 반면 시편은 26개(6.8%)뿐.

부수 결함: 본문 중복 6쌍, `index = 날짜 % 385` 라 품질이 달력에 고정(크리스마스=축도,
새해=문장 조각), 잘 만들어진 `_POPULAR_VERSE_REFS` 170개는 `/random` 이 사문화돼 방치.

**AI 풀이가 부실한 것도 여기서 온다.** 구절 자체에 독립된 메시지가 없으면 풀이도 붕 뜬다.

## 확정된 기준 (사용자 결정 — 임의로 바꾸지 말 것)

**핵심 질문: 읽고 바로 와닿고 이해되는가?**

- **위안** — 지금 아픈 사람에게 건네는 말 / **교훈** — 살아가는 데 도움이 되는 통찰
- **찬양·신앙고백·교리 서술은 제외.** 「여호와는 나의 X시니」 형태의 정체 서술은
  아무리 유명해도 뺀다 — **시편 23:1, 요한복음 3:16도 제외**했다.
- 앱 사용자는 **대부분 기독교인**이다. "비신자도 읽히는가"가 기준이 아니다.
  「외인」(교회 밖 사람) 같은 표현은 문제되지 않는다.
- **목록 개수는 목표가 아니라 결과값이다.** 반복 주기는 신경 쓰지 않는다.
- **길이 하한 없음**(`MIN_LEN = 0`). 좋은 문장은 저절로 길어지고, 짧아도 심금을
  울리면 좋은 문장이다 — 「안심하라 내니 두려워 말라」(15자).
- **합본 허용** — 문장이 끊길 때만. 길이를 채우려고 붙이지 않는다(시편 119:105가
  106절에 희석된 사고가 있었다). 표기는 「시편 40:1-2」.
- **기도문 포함** — 「…하소서」로 끝나는 간구도 좋은 것은 넣는다.
- **서사 껍데기 제거(B 방식) 허용** — 절 안의 "예수께서 가라사대 … 하시니라" 같은
  서술만 벗기고 말씀은 한 글자도 안 고친다. 표준 표기 `b`를 붙인다(요한복음 8:11b).
  **어미까지 다듬는 것(C안)은 하지 않는다.**
- **제외 대상 추가분**: 비하 표현(소경·벙어리·문둥이·병신 등), 가부장적 가정 규범
  (엡 5:22, 골 3:18, 딤전 2:11-12), 종·상전 구절(엡 6:5, 골 3:22, 딛 2:9).

**동음이의 오독 41건이 이 목록의 핵심 발견이다.** 난해 어휘는 독자가 "모르겠다"고
알아채기라도 하지만, 이건 **틀린 뜻으로 매끄럽게 읽히고 넘어간다.**

> 권고 眷顧(돌보심) → 勸告(충고) · 은사 恩賜(선물) → 恩師(스승) · 인자 人子 → 仁慈
> 음부 陰府(스올) → 陰部 · 장부 臟腑(속) → 帳簿 · 백수 白首(백발) → 白手(무직)
> 외식 外飾(위선) → 外食 · 종말로(마지막으로) → 終末 · 하수 河水 → 下水
> 앞잡이(선구) → 앞잡이(부역자) · 비굴한 자(엎드린) → 卑屈 · 적당하게(품위 있게) → 대충

같은 한자어라도 **문맥이 뜻을 잡아주면 통과시켰다.** 「인자와 진리」(잠 3:3)는 떨어뜨렸지만
「나의 인자는 네게서 떠나지 아니하며」(사 54:10)는 남겼고, 「신원하시며」도 뒤에
「공의를 베푸시리이다」가 붙은 시편 140:12는 남겼다. **단어 목록으로 자동 처리하면 안 된다.**

### 2. 표본 40개 검증 — **통과 (3/40 = 7.5%)**

기준은 「걸리는 게 3개 이하」였다. 표본을 세 번 뽑아 그때마다 걸린 것을 고쳤다.

| 회차 | 걸린 수 | 그래서 무엇을 했나 |
|---|---|---|
| 1차(재검토 전) | 13/40 (32.5%) | 기준이 어긋남 → 전수 재검토 착수 |
| 2차 | 7/40 (17.5%) | 12개 탈락 + 빌더 2건 수정 |
| 3차 | 5/40 (12.5%) | **1차 세션 구간(첫 200개)이 느슨한 게 드러남** → 그 구간 141개 재검토, 41개 탈락 |
| 4차 | **3/40 (7.5%)** | 통과. 걸린 3개도 마저 탈락 |

**3차에서 나온 게 이 작업의 교훈이다.** 12건의 지적 중 5건이 첫 200개 구간에서 나왔다
(그 구간은 전체의 25%). 세션이 바뀌면 기준이 미끄러진다 — **표본 검증은 자기가 방금 본
구간이 아니라 전체에서 무작위로 뽑아야 한다.**

재현:

```bash
python - <<'EOF'
import csv,glob,random
cards=[]
for f in sorted(glob.glob('docs/verse_picks/*_cards.csv')):
    cards+=list(csv.DictReader(open(f,encoding='utf-8-sig')))
random.seed(940217)          # 시드를 바꿔 새 표본을 뽑는다
for c in random.sample(cards,40): print(c['reference'],'\t',c['text'])
EOF
```

## 이번에 고친 빌더 버그 (재발 주의)

- **「…하여」가 완결로 통과** — 마태 6:3「왼손이 모르게 하여」. `CONNECTIVE` 에 `하여` 추가.
- **「하셨더라」 서사 꼬리가 남음** — 마가 11:25「…주시리라 하셨더라」. `FRAME_TAIL` 에 추가
  (`하시었더라`·`하시더라`·`하였더라` 는 있었는데 `하셨더라` 만 빠져 있었다).
- **`status` 가 apply 뒤에 185% 를 찍음** — 판정 793건 vs 카드 429개를 나눠서 그랬다.
  걸러진 뒤에는 진행률 대신 「재검토 완료」를 보여주도록 수정.

- **어미 훼손** — `\s*하니라$` 규칙이 공백 없이도 매칭돼 「그 날에 족**하니라**」를
  「…족」으로 잘랐다. 공백을 반드시 요구(`\s+`)하도록 수정. 4개 복구.
- **합본 ↔ 하반절 충돌** — 껍데기를 벗긴 절에 뒤 절을 붙이면 그 절의 서사가 도로
  딸려 온다(요한 8:7 + 8:8 = 「…돌로 치라! 하시고 다시 몸을 굽히사」).
  `partial` 이면 합본하지 않도록 수정.
- **끊김 판정 누락** — 「…노니」(빌 4:11), 「…것이니」(마 7:7)가 완결로 통과했다.
  반대로 팔복의 「…것임이요」는 완결로 둬야 해서 `(?<!임)이요` 로 구분.
